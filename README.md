## How I Use This Repo
1. Pick a topic, read its README, and copy a template as a starting point.
2. Solve the checklist problems in order (Easy -> Medium -> Hard).
3. Tick off `[ ]` -> `[x]` in the topic's README as problems are solved.
4. Save each solution as `<problem-slug>.cpp` in that topic's folder.
